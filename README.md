# Prestige Motors

Plataforma de locação de carros importados, desenvolvida com React, Vite e Tailwind CSS.

## Funcionalidades

- Catálogo de veículos com informações e preços por diária.
- Busca por marca e modelo.
- Filtros por categoria.
- Ordenação por preço.
- Formulário demonstrativo de interesse em veículos.
- Validação de dados e datas de locação.

## Tecnologias

- React
- Vite
- Tailwind CSS
- React Router
- Lucide React

## Como executar

Clone o repositório:

```bash
git clone https://github.com/CP6WEB/cp6web.git
cd cp6web
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

## Observação

O formulário de interesse é demonstrativo. Os dados não são enviados nem armazenados em um servidor.
